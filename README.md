## 这是什么

CPChart 是一个把角色关系画成**同心圆关系图**的工具：

- **圆心** = 核心人物（通常是主角 / 你最关心的人）。
- **往外一圈圈** = 与核心关系由近到远的角色。
- **粗线** = 表达「有多喜欢」（本命 / 很喜欢 / 路好 / 不吃）。
- **细线** = 表达「是什么关系」（爱情 / 友情 / 亲情 / QPR / 自建词）。
- **箭头** = 表达方向（谁指向谁）。

## 怎么用

1. 打开上面的**网页版链接**即可开始（无需下载、无需注册）；想离线使用，再下载压缩包解压，双击 `index.html`。
2. 在「人物名单」里添加角色，用画布右侧「+」菜单调整布局、画连线、改样式。
3. 数据自动存在浏览器 `localStorage`；也可通过「保存导出」把数据复制成文本带走，或把别人分享的文本粘贴进来导入。

> 手机端：用手机浏览器打开网页版链接即可访问，触屏手势（双指缩放、单指平移）已适配。

## 数据格式：CPChart 语言

导出的文本遵循 **CPChart 语言**（纯文本，可手写、可复制粘贴、可贴评论区）。

- 填写方式与完整语法见 **`CPChart语言使用说明.md`**（写给填表的人看）。
- 想让 AI 帮你生成，把 **`CPChart-AI生成指引.md`** 整份贴给它、末尾填上作品名即可。
- 旧的分段制格式（`#标题#` 五段式）已停用，但**仍然可以导入**（旧文本无需改写即可识别）。

## 功能特点

- **圆环布局**：单圆心 + 多圈分布，角色自动均分，可拖拽换圈、调节圈半径。
- **多线叠加**：同一对角色可画多条独立连线，底层粗线 + 顶层细线 + 箭头自由组合，互不覆盖。
- **样式表**：喜好度层 / 关系类型层 / 箭头方向，增删改实时刷新全图；图例三段分行（粗线 → 细线 → 箭头含义）。
- **人物管理**：名单批量导入、头像设置、喜好度标记、显示模式一键切换。
- **手势操作**：双指缩放、单指平移，适配移动端触屏。
- **数据快照**：文本交换（CPChart 纯文本 / 压缩数据串），`localStorage` 自动保存草稿。
- **成品输出**：隐藏 UI 生成预览图，网页版可长按 / 下载保存。
